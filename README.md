# 인생시계

태어난 날을 넣으면 내 인생이 지금 몇 시인지, 남은 시간과 남은 주말·여름·크리스마스가 몇 번인지 세어 주는 웹 페이지예요.

뿅글이(@bbyonggeul) 제작.

## 들어 있는 것

- **남은 시간 일력**: 기준 나이까지 남은 시간을 년, 개월, 주, 일, 초 단위로 보여줘요.
- **인생시계**: 태어난 날을 0시, 기준 나이가 되는 날을 24시로 놓았을 때 지금이 몇 시인지 보여줘요.
- **남은 횟수**: 주말, 보름달, 봄, 여름, 크리스마스, 생일이 앞으로 몇 번 남았는지 세요.
- **주 단위 달력**: 한 줄이 1년, 한 칸이 1주쯤인 달력에 지나온 주와 남은 주를 표시해요.

## 계산 기준

- 기준 나이 기본값 83.7세(여성 86.6세, 남성 80.8세)는 국가데이터처(옛 통계청) 2024년 생명표의 기대수명이에요. 갓 태어난 아기 기준 숫자라서, 이미 여기까지 살아온 사람에게는 조금 짧게 잡혀 있어요.
- 주말은 토요일과 일요일을 묶어 한 번으로 세요. 봄은 3월부터 5월, 여름은 6월부터 8월이에요.
- 보름달은 평균 주기 29.53일로 계산해서 실제와 한 번쯤 다를 수 있어요.
- 넣은 생년월일은 어디로도 보내지 않고 그 기기의 브라우저에만 저장해요.
